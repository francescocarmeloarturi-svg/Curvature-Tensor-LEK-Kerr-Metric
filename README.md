## Lorentzian–quasi-Euclidean Kerr (LEK) metric <br> <br>
This repository contains the Mathematica implementation used to compute the geometric and curvature quantities associated with the Lorentzian–quasi-Euclidean Kerr (LEK) metric in Doran coordinates, as discussed in the research paper:
"The Lorentzian quasi-Euclidean Kerr black hole" by Francesco Carmelo Arturi, Giuseppe Ficarra and Sergio Servidio (need to add link when we have preprint). <br><br>
The notebook LEK_Kerr_Doran_TensorAnalysis.nb performs a complete symbolic computation of the metric tensor, Christoffel symbols, Riemann tensor, Ricci tensor, Ricci scalar, and the Kretschmann invariant for the new proposed modified Kerr geometry featuring a signature–changing function.
