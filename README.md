Tensor analysis for the Lorentzian–quasi-Euclidean Kerr metric in Doran coordinates. <br>
This repository contains the full Mathematica implementation used to compute the geometric and curvature quantities associated with the Lorentzian–Quasi-Euclidean (LKE) Kerr metric in Doran coordinates, as introduced in the accompanying research article: "Atemporality in Kerr Spacetime: The Lorentzian-Quasi-Euclidean Kerr Model" (link).
The notebook LKE_Kerr_Doran_TensorAnalysis.nb performs a complete symbolic computation of the metric tensor, Christoffel symbols, Riemann tensor, Ricci tensor, Ricci scalar, and the Kretschmann invariant for the modified Kerr geometry featuring a signature–changing function.
