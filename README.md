Analysis for the Lorentzian–quasi-Euclidean Kerr metric in Doran coordinates. <br>
This repository contains the full Mathematica implementation used to compute the geometric and curvature quantities associated with the Lorentzian–quasi-Euclidean Kerr (LEK) metric in Doran coordinates, as introduced in the article: "The Lorentzian quasi-Euclidean Kerr black hole" (link).
The notebook LEK_Kerr_Doran_TensorAnalysis.nb performs a complete symbolic computation of the metric tensor, Christoffel symbols, Riemann tensor, Ricci tensor, Ricci scalar, and the Kretschmann invariant for the new proposed modified Kerr geometry featuring a signature–changing function.
